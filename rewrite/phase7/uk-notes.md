# uk notes
Glossary: table=таблиця, field=поле, relationship=зв'язок, diagram=діаграма, area=область, note=нотатка, schema=схема,
custom type=власний тип, index=індекс, view=подання, canvas=полотно, side panel=бічна панель, primary key=первинний ключ,
foreign key=зовнішній ключ, check constraint=обмеження перевірки, cardinality=кратність. Register: ви.
Plurals: _one/_few/_many/_other written out; _other (fractions) uses the genitive singular, same as _few where the noun allows.
Clipboard/count messages that were not plural keys in en use "Скопійовано таблиць: {{count}}" to avoid needing plural forms.
Doubts: "Скасувати дію"/"Повторити дію" for Undo/Redo; nullableShort "N" kept; "Правка" for the Edit menu; "подання" for database views.
