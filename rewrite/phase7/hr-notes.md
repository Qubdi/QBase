# hr (Croatian) notes
Glossary: table = tablica, field = polje, relationship = veza, diagram = dijagram, area = područje, note = bilješka, schema = shema, custom type = prilagođeni tip, view = pogled, index = indeks, primary/foreign key = primarni/strani ključ.
Plurals: `_one`, `_few`, `_other` (few added for 2-4). Register: formal "vi", imperative plural-polite.
Doubts: count phrases were worded so that the `_other` form (0, 5+) and the `_few` form stay grammatical, using the "label: {{count}}" shape in some `_other` strings. "Kind" appears as "Vrsta" (to separate from "Tip" = type).
