# te (Telugu) notes
Glossary: table = పట్టిక, field = ఫీల్డ్, relationship = సంబంధం, diagram = రేఖాచిత్రం, area = ప్రాంతం, note = గమనిక, schema = స్కీమా, custom type = అనుకూల రకం, view = వ్యూ, index = ఇండెక్స్, primary/foreign key = ప్రైమరీ/ఫారిన్ కీ.
Plurals: `_one` and `_other` (checked with the rule set in the brief). Register: neutral polite imperative (-ండి).
Doubts: SQL keyword-level messages keep English technical terms; "links" (rail) = లింక్‌లు, "Extras" = అదనపు. Telugu has no plural marker difference in a few counted phrases, so `_one` and `_other` differ only in the noun form.
