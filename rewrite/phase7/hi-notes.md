# hi notes

Glossary: table टेबल, field फ़ील्ड, relationship संबंध, diagram डायग्राम, area क्षेत्र, note नोट, schema स्कीमा, custom type कस्टम टाइप, view व्यू, index इंडेक्स, primary/foreign key प्राइमरी/फ़ॉरेन की, cardinality कार्डिनैलिटी. Register: आप.

Plural: `_one` and `_other` (hi treats 0 and 1 as `one`).

Left as in English: DBML, Supabase, Timescale, MySQL 5.7, Cloudflare D1, null, NOT NULL, UQ, N, Enum, 1:1, 1:N, Ctrl, ⌘, #rrggbb.

Doubts:
- Common technical loanwords (इम्पोर्ट, एक्सपोर्ट, कैनवास, ऐरे) are transliterated rather than replaced by Sanskritised terms.
- `import.skipped_*` embeds `{{kind}}` before "स्टेटमेंट"; no inflection possible.
- Gender agreement of "टेबल" (feminine) in `diagnostics.found_*`, `into.*`; "व्यू" counted as masculine.
- `hover.key` rendered "की" (reads as the word "key").
