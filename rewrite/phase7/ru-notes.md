# ru notes

Glossary: table таблица, field поле, relationship связь, diagram диаграмма, area область, note заметка, schema схема, custom type пользовательский тип, view представление, index индекс, primary/foreign key первичный/внешний ключ, cardinality кратность. Register: вы (mostly impersonal imperative).

Plural: `_one`, `_few`, `_many`, `_other` for every English `_one/_other` pair (other = genitive singular form, used for fractions).

Left as in English: DBML, Supabase, Timescale, MySQL 5.7, Cloudflare D1, null, NOT NULL, UQ, N (nullableShort), 1:1, 1:N, Ctrl, ⌘, #rrggbb.

Doubts:
- `import.skipped_*` embeds `{{kind}}` after the noun ("оператор {{kind}}"); declension of the kind word is not possible.
- `importing.box.found` ("Найдено: {{tables}} и {{links}}.") and `diagnostics.found*` compose count phrases; "Найдена 1 таблица" agrees with the count, but when composed with `foundWithViews` ("{{tables}} и {{views}} для импорта") gender agreement is approximate.
- `hover.*` labels (type, null, key...) are lower-case technical captions; `references`/`referencedBy` rendered "ссылается на"/"на неё ссылаются" (feminine assumes "таблица").
- `rail.visuals` "Прочее" and `rail.customTypes` "Типы" are short on purpose for the narrow rail.
