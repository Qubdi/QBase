02

Gate — database model rule

Not a task: every migration below must pass all ten before its step is ticked.

The ten checks
#CheckRule
1ShapeOne fact in one place; plural snake_case tables, _at times, <table>_<cols>_idx
2Typesuuid ids, identity bigint for append-only, timestamptz, enum or CHECK for closed sets
3IntegrityNOT NULL by default, FKs (audit excepted), CHECKs, case-insensitive natural keys
4Foreign keyson delete chosen and commented; every FK column indexed
5IndexesEach justified by a named query; partial for hot subsets; drop unused after load test
6QueriesNo select * on big jsonb; aggregate in SQL; no N+1; keyset paging; capped limit; EXPLAIN in commit
7MigrationsOne per step, named, never edited; safe on populated DB; tested on throwaway Postgres
8LifecycleRetention in runMaintenance with a test; secrets never logged or returned; no IPs
9ExplainedOne-line comment in schema.ts per new table and odd column
10Review noteCommit says what changed, index → query, retention, how to undo
